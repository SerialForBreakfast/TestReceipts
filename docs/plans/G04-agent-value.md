# G04 — Optional agent interface and repeated-use evidence

Task ledger: [G04](../../Tasks.md#g04--agent-integration-and-repeated-use-value). This milestone is deferred; no model calls are part of the Go port.

If prioritized, expose the same comparison core through MCP without adding a second parser or generated answers. Specify request scope, result-size limits, error states, original-source references and escalation/fetch behavior. Compare CLI and MCP facts before measuring agent overhead.

A later study must retain capable parser and ready-made query baselines, and add a baseline script that already accepts URLs. Give every arm equivalent cache and script reuse. Separate setup for a new environment from repeated investigations in an existing environment. Do not force extra calls or raw XML reads on a baseline.

Freeze held-out run selection, questions, scoring and budget before trials. Count full-investigation model input/output, cached/uncached tokens, tool definitions, retries and follow-up reads. Preserve failed attempts, exact inputs/outputs, human-readable charts and independent checks. Evaluate completeness and correctness separately from cost. A Go port does not itself create agent-token savings.
